# System Requirements

__Software Requirements__

- Ubuntu 24.04 with latest OpenStack (master) installed.
- Latest [python-3parclient 4.4](https://pypi.org/project/python-3parclient/).

If using prior versions of OpenStack, kindly refer 
[support matrix](https://spock.corp.int.hpe.com/spock/utility/document.aspx?docurl=Shared%20Documents/sw/array_3par/hpe_openstack_compatibility_matrix.pdf).

__Network Requirements__

- iSCSI: multipathing strongly recommended.
- FC: zoning between initiators and storage ports.

__Storage Requirements__

- HPE Alletra MP B10000 OS v10.5.
- HPE Alletra 9000 OS v9.5.
- HPE Primera OS v4.5.
- HPE 3PAR OS v3.2.1.
- WSAPI server must be enabled.
- At least one Common Provisioning Group (CPG) should be available.
